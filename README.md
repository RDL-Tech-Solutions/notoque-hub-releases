# NoToque Hub — releases

Instaladores públicos do **NoToque Hub** (aplicativo Windows de impressão e operação local do NoToque).

Este repositório guarda apenas os arquivos de cada versão, na aba **Releases**:

- `NoToque-Hub-Setup-<versão>.exe` — instalador
- `NoToque-Hub-Setup-<versão>.exe.blockmap` — mapa de blocos para atualização diferencial
- `latest.yml` — metadados da versão (nome, tamanho e SHA-512)

Não há código-fonte aqui. O download para clientes e a atualização automática são feitos pelo NoToque (www.notoque.com.br); o Hub só funciona pareado a uma conta com plano Premium.
